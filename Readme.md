# Orion & Atom CMS Development and Bugfix Repository

Bu repo, **Orion CMS** ve **Atom CMS** projelerindeki hataları çözmek ve yeni özellikler eklemek amacıyla oluşturulmuştur. Katkıda bulunmak isteyen herkes açık kaynak ruhuyla projeye destek olabilir.
This repo is created to fix bugs and add new features for **Orion CMS** and **Atom CMS** projects. Everyone is welcome to contribute in the spirit of open source.
